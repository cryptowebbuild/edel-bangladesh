# 👑 Edel Bangladesh — Premium Churi & Bridal E-Commerce Web App

High-converting, automated e-commerce web application designed for **Edel Bangladesh** (facebook.com/edelbangladesh).

## ✨ Key Features
- **1-Click WhatsApp Order Automation**: Generates official digital order slip with Order ID and itemized summary sent directly to WhatsApp.
- **Interactive Bangle Size Selector**: Supports 2.4, 2.6, 2.8 bangle sizes with built-in measurement guide.
- **Custom Gift Box Builder**: Real-time personalized gift hamper creator with customized handwritten notes.
- **Gamified Delivery Fee**: Dynamic free delivery progress bar (৳1,200 threshold).
- **Owner ROI Pitch Panel**: Built-in comparison modal for merchant pitch showing why a website increases sales.
